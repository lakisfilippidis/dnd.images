name: Аптекарь
group: alchemy
req: Набор аптекаря

**Реторта.** Варя дозу, ты можешь **убрать из неё один вредный эффект** — чтобы зелье не усыпляло пьющего. За длинный отдых ты варишь **на одну дозу больше**. Эту черту **можно брать повторно**: каждый следующий раз — ещё один убираемый эффект, доза добавляется только один раз.
