# Вардан Саркисян

## Основная информация

**Класс:** **[Плут (Rogue)](../../Classes/rogue/)** — шпион, заговорщик

**Предыстория:** Торговый посредник

**Мировоззрение:** Нейтрально-добрый

**Раса:** Человек (гурдиец)

**Уровень:** 7

**Бонус мастерства:** +3

**Спасброски:** Ловкость, Интеллект

**Скрытая атака:** 4d6

- **Рапира:** 1d8+2 колющий, +5 (Ловкость +2, Владение +3), фехтовальное.

## Черты характера

**Положительные:** Запоминает всех, кого встретил; искренне любит людей, за которыми следит.

**Отрицательные:** Сам уже не всегда уверен, какое из имён настоящее; никому не говорит всей правды.

---

## Внешность

Мужчина лет тридцати пяти, приятное незапоминающееся лицо, аккуратная борода, которая по необходимости исчезает. Говорит на пяти языках без акцента.

---

## Краткая биография

Официально — посредник гурдийских купцов в лиренийских портах. На деле собирает для князей Гурдийских гор сведения о передвижениях Рума: кто куда везёт зерно, какие гарнизоны сменились, кто из имперских чиновников недоволен. Ни разу не поднял клинок по работе и гордится этим.
